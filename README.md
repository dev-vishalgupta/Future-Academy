Welcome to the official repository of **Future Academy**, a premier coaching institute based in **Isuapur, Saran, Bihar**. Future Academy delivers concept-driven education in **Mathematics and Science** for students from **Class 8th to 12th (BSEB & CBSE)**, along with specialized **Board Crash Courses**, **ITI Preparation**, and **Polytechnic Entrance Preparation**.

---

## 🌟 Key Highlights & Features

- 🎨 **Modern Ed-Tech Design System**: High-contrast, clean typography (`Outfit` & `Plus Jakarta Sans`), glassmorphic cards, smooth gradients, and subtle micro-animations.
- 📐 **Custom STEM Vector Hero**: Scalable, animated vector illustration showcasing mathematical calculus, physics formulas, geometry graphs, and interactive digital learning.
- 🌓 **Intelligent Theme Engine**: Light theme default with custom dark theme toggle, saved persistently to `localStorage` (`fa_theme`).
- 📱 **Mobile-First Responsiveness**:
  - Fixed sticky **Quick-Action Contact Bar** on mobile devices (**WhatsApp**, **Call Now**, **Google Maps Directions**).
  - Background scroll-locking mobile navigation drawer.
  - Fluid `clamp()` typography and touch-optimized action targets.
  - Strict layout containment with zero horizontal scrolling.
- 📍 **Verified Location & Google Maps Integration**: Direct 1-tap navigation to the academy at **1st Floor, Isuapur Bajar, Near KYP, Saran, Bihar – 841411**.
- 💬 **Instant WhatsApp Inquiries**: Direct one-click messaging to academy counselor (+91 9309323018).

## 🚀 Getting Started Locally

1. **Clone the repository**:
   ```bash
   git clone https://github.com/dev-vishalgupta/Future-Academy.git
   cd Future-Academy
   ```

2. **Open with Live Server**:
   - You can serve the static files with any local HTTP server:
     ```bash
     # Using Python
     python -m http.server 3000

     # Using Node.js npx serve
     npx serve .
     ```
   - Open your browser at `http://localhost:3000` or `http://localhost:3000/index.html`.
